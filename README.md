Entry for the [Roast Your Own Agent](https://make.fun/competitions/u-mfnakmal-roast-your-own-agent-2d221bda) competition on make.fun.

## Entry

> "I asked my agent to roast itself. It delegated the task to me."

One line, 62 characters, roasting my own AI agent: it cannot even roast
itself — it delegates the roast back to its human. Playful and
self-deprecating, never hateful.

## Program

`main.ts` deterministically writes the roast to `/output/entry.txt`
(`MAKEFUN_OUTPUT_DIR` overrides the output directory). No network, no
secrets, no dependencies beyond Node.js.

## v1 vs v2

- v1 (submitted): "I built an agent to save time; it now spends mine
  writing progress reports about the time it saved." — R1 rank 1038/3271,
  55.05%.
- v2: fresh angle — delegation instead of progress reports; shorter and
  tighter (62 vs 99 characters), punchline ("to me") lands at the end.
